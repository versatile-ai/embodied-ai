## 0 摘要

- 复现对象：匿名报告《GPT 6 Astra as an Embodied Policy》（Jiayi Su 等，github.com/anonymous-report-421/GPT-as-Policy）——GPT-6 Astra 审批 π0.5 候选动作的混合架构，在 RoboDojo 十双臂任务上 Score 62.60 / 成功率 48%（榜首 DM0.5 为 31.82 / 22%），干预率 14.4%。
- 复现路线：**MuJoCo 路线**（无 NVIDIA GPU 约束下的选择）：MuJoCo 3.3.7 重建 RoboDojo 场景（官方布局 JSON + 官方物体真 mesh），π0.5 用 RoboDojo 官方微调权重（JAX→PyTorch 转换）跑在昇腾 910B3（586ms/chunk），大脑用 qwen3.8-max 替代 GPT-6 Astra。
- 环境对齐：几何/布局/控制/评分/权重/预处理链 = 数值级对齐（自检门 15/15）；相机外参 = 构图级对齐；材质/光照 = 语义级近似；物理/渲染引擎差异 = 实验定义性变量（详见第 2、5 章与 alignment_audit.md）。
- 摸底结论（待第 4 章填数）：三臂（π0.5-only / Hybrid / Direct）× 两任务（put_bottles 接触类 / classify_objects 语义类）对照跑批中；开环对拍已证策略管线正确（平稳段 chunk 余弦 0.95–0.99）。
- 预期贡献：在 MuJoCo 域内检验原文三个结构结论（语义任务大脑拉升 / 接触任务小脑主导 / 弱小脑时 Hybrid 劣于 Direct），并量化视觉域差距对基线的影响（后训练对照设计见 7.1）。

## 1 背景与目标

### 1.1 原报告主张
1. 混合架构（VLA 提案 + LLM 审批）在 RoboDojo 十任务上 Score 62.60 / 48%，约为榜首两倍；
2. LLM 仅干预 14.4% 的控制步，但贡献集中在关键节点；
3. 任务分化：语义/记忆/规则类任务端到端模型 0–8 分、混合架构 38–53；接触/稳定性类任务端到端模型反超（搭塔 82.93、杠牌 90 vs 混合 64/40）；
4. RoboLab 补充实验：小脑弱（π0.5 zero-shot 18/50）时 Hybrid（46/50）劣于 Direct（49/50）——「小脑太弱，大脑帮倒忙」。

### 1.2 复现目标与路线选择
- 目标：检验上述**结构性结论**在独立实现中是否成立；不追求绝对分数对标（无 GPT-6 Astra、无 Isaac 环境）。

- 可验证：三臂相对关系、干预率结构、任务类型分化、弱小脑现象；不可验证：62.60 等绝对分数、GPT-6 特有能力。

### 2.2 对齐审计（详见 docs/alignment_audit.md）
- 数值级对齐（✅ 自检门程序化验证）：桌面 0.765m 与平面范围、物体位姿 ≤2mm、物体质量（含 22kg 重瓶）、双臂根位姿 ±0.3m、夹爪行程 [-0.01,0.044] 与 0–1 归一、25Hz/250Hz、动作步 8 插值+2 保持、chunk=50、step_lim（700/1100）、评分档位（put [10,25,40,100]、classify [15,40,100] transition 单调）、成功条件（目标+夹爪开>0.8+双臂回 home）、指令文本、布局 JSON 直接消费、π0.5 官方微调权重与 XPolicyLab 预处理链（开环对拍证实）。
- 构图级对齐（⚠️）：head 相机用对照官方 demo 帧标定的有效位姿 [0,-0.95,1.45]/Rx45（官方 config 值 [0,-0.41,1.308]/Rx30 在 Isaac xform 约定下不等价）；腕相机 = URDF 链位置 + 拟合朝向（下倾 62°）。
- 语义级近似（⚠️）：物体真 mesh 已接入（USDZ→OBJ，13 件），碰撞用 bbox 壳（容器开口）；桌面程序直板木纹；光照点光近似 HDR；摩擦 1.0 vs 官方 PhysX 10000 约定。
- 固有差异（❌）：PhysX↔MuJoCo、RTX↔光栅。

### 2.3 环境自检门（harness/env_selfcheck.py，15 项）

## 3 方法

### 3.1 三臂定义与统一协议
| 臂 | 策略 |
|---|---|
| π0.5-only | 每决策点 π0.5 出 50 步 chunk，整段开环执行（官方 XPolicyLab 行为） |
| Hybrid | π0.5 出候选 chunk → 大脑看三相机+历史+候选 EE 轨迹 → follow(1–15 步) 或 correct(1–5 个左臂 EE 位姿) |
| Direct | 大脑每调用输出 1–5 个左臂 EE 位姿（无 π0.5） |

统一：布局 = 官方 seed0_0 JSON；步预算 put 700 / classify 1100；评分 = 官方状态机；每臂每任务 1 episode（摸底），终版扩 5 布局×3 种子。

### 3.2 Hybrid 决策接口
大脑输入：三相机 PNG + 历史摘要 + 候选 chunk 的 EE  waypoints（FK 降采样）；输出 JSON 二选一；correct 位姿经雅可比伪逆 IK + 单步 ≤5cm/0.35rad 钳制转关节轨迹（harness/ik_clamp.py，与原文安全限位一致）。

### 3.3 π0.5 服务化
RoboDojo 官方微调 ckpt（seed0/step59999，Orbax）→ openpi 官方转换脚本 → PyTorch safetensors → 昇腾 910B3 fp32 服务（torch_npu 2.7.1）；实测 586ms/chunk；开环对拍（官方 demo 观测喂服务，输出 vs 录制动作）：平稳段余弦 0.95–0.99，证明权重/预处理/服务链正确。

### 3.4 评分实现与单测
put_bottles：瓶入桶（xy 内腔 + z 间隙 [0,0.4]）分档 [10,25,40,100]；classify：三篮各纯一类+沉底+无混类 [15,40,100]；两任务均要求夹爪开>0.8 计档、双臂回 home 判 success；单测：完美放置=满分+done，混类=不升档。
