## 缺陷定位

1. `harness/simsvc.py` 的 camera_stand 使用 `mjJNT_FREE`，几何又关闭碰撞。注释说静态装饰物，实际可自由落体；其消失会改变策略视觉输入。
2. `bottles_in_bin()` 遍历全部 `obj_body_ids`，仅排除 dustbin，没有限制 bottle 类型，因此装饰物也能计数。
3. π0.5 输出形状和数值有效不代表符合控制接口范围。`client.py` 的 infer 只校验形状和有限值，follow 直接发送原始动作；服务拒绝越界夹爪值。前一局临时实验循环做过夹爪限幅并记录次数，但通用客户端仍未修复。
4. 分类场景编译大型网格时发生内存不足；应测量峰值、检查 mesh 复杂度与会话资源释放，再决定优化方案，不应将其报告为正常。
5. 垃圾桶位移已实测复现；确切原因仍需检查初始碰撞、桶底高度及静态/动态建模，不能仅由当前数据推断。
